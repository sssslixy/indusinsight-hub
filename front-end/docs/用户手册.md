# 工析智枢： IndusInsight Hub 用户手册

本文档面向平台最终用户，说明如何登录平台、浏览资源、创建和使用智能体、管理 Skill、Tool、知识库、收藏、公告与个人资料。

## 1. 平台概览

本平台用于面向工业大数据解析场景构建、管理和运行智能体。用户可以在平台中完成以下工作：

- 创建并发布智能体，配置数据处理、特征工程、模型选型、超参数优化、结果分析等多阶段流程。
- 在智能体工作台中提交自然语言需求和数据文件，查看流式运行过程、历史会话和输出文件。
- 创建、发布和管理 Skill 与 Tool，作为智能体可调用的能力组件。
- 创建知识库，上传文档，配置解析、切片、向量化和检索策略。
- 浏览社区公开资源，收藏智能体、Skill、Tool 和知识库。
- 查看公告、个人资料、账号安全和个人数据概览。

## 2. 快速上手流程

首次使用建议按以下顺序完成：

1. 打开平台首页，进入登录页。
2. 使用账号密码或手机号验证码登录。
3. 进入工作台，查看快捷入口和个人数据概览。
4. 如果已有公开资源需求，可以先进入社区浏览并收藏智能体、Skill、Tool 或知识库。
5. 如果需要构建自己的能力，先创建知识库、Skill 或 Tool，再创建智能体并绑定这些能力。
6. 进入智能体使用工作台，上传数据文件并输入分析需求，等待运行结果。
7. 在历史会话中回看任务过程，在输出文件中下载生成产物。

## 3. 账号登录与退出

### 3.1 账号密码登录

操作步骤：

1. 从平台首页点击登录入口，进入登录页。
2. 选择“账号登录”。
3. 输入账号和密码。
4. 如需保存账号，可勾选“记住我”。
5. 点击“登录”进入工作台。

### 3.2 手机号验证码登录

操作步骤：

1. 在登录页选择“手机号登录”。
2. 输入手机号。
3. 点击“获取验证码”，等待验证码倒计时。
4. 输入验证码后点击“登录”。
5. 如果是新用户，平台会提示初始密码信息，建议后续进入个人中心修改密码。

### 3.3 退出登录

操作步骤：

1. 登录后在顶部导航栏找到用户菜单。
2. 点击用户菜单中的“退出登录”。
3. 平台会清除当前登录状态并返回登录页。

注意事项：

- 未登录访问工作台、社区、创建页、个人中心等受保护页面时，系统会自动跳转到登录页。

## 4. 工作台

工作台是登录后的主入口，包含快捷功能入口、资源聚合和个人数据概览。

### 4.1 快捷入口

工作台支持快速进入：

- 创建智能体、创建 Skill、创建 Tool、创建知识库。
- 智能体社区、Skill 社区、Tool 社区、知识库社区。
- 我的智能体、我的 Skill、我的 Tool、我的知识库。
- 我的收藏、个人资料、用户手册。

操作方式：在工作台快捷入口卡片中点击目标功能，即可进入对应页面。

### 4.2 内容聚合与数据概览

工作台还可以查看：

- 系统公告摘要。
- 热门智能体、热门 Skill、热门 Tool、热门知识库。
- 近期收藏内容。
- 我的智能体、Skill、Tool、知识库数量。
- 收藏的各类资源数量。

## 5. 资源社区

资源社区用于浏览公开发布的能力资源。平台当前包含智能体社区、Skill 社区、Tool 社区和知识库社区。

### 5.1 智能体社区

功能说明：

- 浏览公开发布的智能体。
- 按智能体名称搜索。
- 按最新发布、收藏最多、浏览最多排序。
- 分页浏览结果。
- 进入智能体使用页。
- 从社区进入智能体使用页后，可以收藏或取消收藏该智能体。

操作步骤：

1. 从工作台点击“智能体社区”。
2. 使用搜索框输入智能体名称关键词。
3. 使用排序条件调整列表顺序。
4. 点击目标智能体进入使用页。
5. 如需后续快速访问，可点击收藏按钮。

### 5.2 Skill 社区

功能说明：

- 浏览公开 Skill。
- 按名称搜索。
- 按类别筛选，例如数据处理、特征工程、模型选型、超参数搜索、结果分析、其他。
- 按最新发布、收藏最多、浏览最多排序。
- 查看 Skill 详情。
- 收藏或取消收藏 Skill。

操作步骤：

1. 从工作台点击“Skill 社区”。
2. 在搜索框中输入 Skill 名称关键词，点击“搜索”。
3. 如需缩小范围，使用类别筛选，例如数据处理、特征工程、模型选型等。
4. 使用排序条件查看最新发布、收藏最多或浏览最多的 Skill。
5. 点击目标 Skill 进入详情页。
6. 在详情页或卡片操作区点击“收藏”或“取消收藏”。

### 5.3 Tool 社区

功能说明：

- 浏览公开 Tool。
- 按 Tool 名称搜索。
- 按 Tool 类别筛选。
- 按最新发布、收藏最多、浏览最多排序。
- 查看 Tool 详情。
- 收藏或取消收藏 Tool。

操作步骤：

1. 从工作台点击“Tool 社区”。
2. 在搜索框中输入 Tool 名称关键词，点击“搜索”。
3. 根据 Tool 类别筛选结果。
4. 使用排序条件查看最新发布、收藏最多或浏览最多的 Tool。
5. 点击目标 Tool 查看详情。
6. 需要后续使用时，点击“收藏”；已收藏的 Tool 可再次点击取消收藏。

### 5.4 知识库社区

功能说明：

- 浏览公开知识库。
- 按知识库名称搜索。
- 按最新发布、收藏最多排序。
- 查看知识库基本信息、文档数、切片数、收藏数等摘要。
- 收藏或取消收藏知识库。

操作步骤：

1. 从工作台点击“知识库社区”。
2. 在搜索框中输入知识库名称关键词。
3. 使用排序条件查看最新发布或收藏最多的知识库。
4. 在知识库卡片中查看文档数、切片数、收藏数等摘要，判断是否符合当前任务。
5. 点击“收藏”后，可在“我的收藏”中快速找到该知识库。

## 6. 智能体使用工作台

智能体使用工作台用于提交分析需求、上传文件、查看运行过程和下载输出结果。

### 6.1 进入智能体使用页

进入方式：

- 从智能体社区点击某个智能体。
- 从“我的智能体”点击“继续使用”。
- 从智能体详情或使用入口进入智能体使用工作台。

页面主要区域：

- 顶部智能体信息卡片：显示名称、简介、图标、状态、收藏入口等。
- 左侧历史会话：显示当前智能体的历史任务会话。
- 中间对话区：展示用户消息、智能体回复、运行状态、任务产物。
- 底部输入区：输入自然语言需求，上传数据文件，切换运行模式。

### 6.2 新建会话与发送需求

操作步骤：

1. 进入智能体使用页。
2. 如需开始全新任务，点击“新建会话”。
3. 在输入框中输入自然语言需求。
4. 根据需要上传数据文件。
5. 选择普通模式或专业模式。
6. 点击发送按钮。

模式说明：

- 普通模式：适合问答、解释、咨询类任务。
- 专业模式：适合机器学习流水线、代码生成、报告产出等完整分析任务。

发送前检查清单：

- 已选择正确智能体。
- 当前会话是否需要新建；如果是新任务，建议先新建会话。
- 已输入明确需求，例如分析目标、目标字段、希望输出的报告或代码内容。
- 专业模式下已上传必要数据文件。
- 模式切换已选择为普通模式或专业模式。

### 6.3 上传任务文件

操作步骤：

1. 点击输入区的上传按钮。
2. 选择本地任务文件。
3. 文件会先显示在输入区的待发送列表中。
4. 如选择错误，可点击移除。
5. 点击发送后，平台会将文件与需求一起提交。

注意事项：

- 专业模式下通常需要上传待分析数据文件。
- 文件上传失败时，对话区会显示错误信息，请检查文件格式、文件大小和网络状态后重试。

### 6.4 查看运行过程

任务运行时，平台会在对话区展示：

- 智能体流式回复内容。
- 当前运行状态提示。
- Markdown 富文本内容，包括表格、代码块、数学公式等。

### 6.5 会话历史管理

支持操作：

- 查看历史会话列表。
- 点击历史会话回看任务内容。
- 重命名会话。
- 删除会话。

操作建议：

- 对重要任务及时重命名，便于后续检索。
- 删除会话前确认是否还需要查看其中的输出文件和过程记录。

### 6.6 文件产物下载

任务完成后，如果生成输出文件，平台会在智能体回复区域展示下载入口。

操作步骤：

1. 等待任务完成提示。
2. 在回复下方或文件区域找到输出文件。
3. 点击文件名或下载按钮。
4. 保存到本地后检查文件内容。

## 7. 智能体创建与管理

### 7.1 创建智能体

进入方式：从工作台点击“创建智能体”。

创建页主要由三部分组成：

- 基础配置：填写智能体名称、简介、图标、是否公开、发布说明。
- 智能体流程：配置五个阶段，包括数据处理、特征工程、模型选型、超参数定义与优化、结果分析。
- 阶段配置：为每个阶段选择模型、填写系统提示词、绑定 Skill和知识库，配置行为开关。

操作步骤：

1. 填写智能体名称和简介。
2. 选择系统图标，或上传自定义图标。
3. 设置是否公开。
4. 在左侧流程中依次选择各阶段。
5. 为当前阶段选择模型。
6. 编辑当前阶段系统提示词。
7. 选择该阶段可调用的 Skill 和知识库。
8. 根据需要设置“只使用已选 Skill”和“允许自主补充流程”两个行为开关。
9. 点击“保存草稿”暂存，或点击“发布”正式发布。

创建页区域说明：

- 左侧“基础配置”：填写智能体对外展示的信息，包括名称、简介、图标、是否公开和发布说明。
- 左侧“智能体流程”：选择当前要配置的阶段。五个阶段需要分别配置，切换阶段后，中间和右侧内容会随之变化。
- 中间“系统提示词”：填写当前阶段的角色、职责、约束和处理原则。
- 右侧“智能体配置”：选择模型，并添加当前阶段可用的 Skill 和知识库。
- 页面顶部操作按钮：用于保存草稿或发布智能体。保存草稿适合暂存未完成配置，发布用于正式启用配置。

添加 Skill 和知识库的操作方式：

1. 在右侧“智能体配置”中找到对应的“添加”入口。
2. 打开选择弹窗后，先选择来源，例如我的、社区、我的收藏；添加 Skill 时还可以选择“运行配置skill”。
3. 使用搜索框输入名称或说明关键词，点击“搜索”。
4. 需要按当前阶段推荐类别过滤时，勾选“仅显示当前推荐类别”；如果来源不支持该筛选，页面会禁用该选项。
5. 点击候选卡片，卡片状态会变为“已选择”。
6. 点击“确认添加”，所选内容会回到当前阶段配置中。
7. 返回创建页后，确认已选内容出现在当前阶段的已选列表中。

行为配置说明：

| 配置项 | 打开后 | 关闭后 | 使用限制 |
| --- | --- | --- | --- |
| 只使用已选 Skill | 当前阶段会把可用 Skill 范围锁定在你已经勾选的 Skill 内。运行时只会从已选 Skill 中选择和调用，不会再通过全局检索补充其他公开 Skill。 | 当前阶段会优先使用已绑定或已选择的 Skill；如果这些 Skill 不能匹配当前需求，运行时允许到全局公开 Skill 中检索语义最匹配的 Skill 作为补充。 | 打开该开关时，当前阶段必须至少选择一个 Skill，否则保存或发布会被校验拦截。该开关只限制 Skill 范围，不会限制已绑定知识库。 |
| 允许自主补充流程 | 在专业模式的代码生成流水线中，系统会检查已读取的 Skill 指南是否覆盖当前阶段所需步骤。如果发现缺口，会把缺失步骤写入“必须补充的需求”，让代码生成阶段自行补齐这些实现步骤。 | 系统不会额外检查 Skill 指南缺口，也不会把缺失步骤追加到代码生成提示中；代码生成主要依据阶段提示词、用户需求、已选 Skill 参考内容、知识库内容和上游阶段结果。 | 该开关用于补充代码生成步骤，不等同于自动寻找新的 Skill。是否允许检索其他 Skill 由“只使用已选 Skill”决定。 |

添加 Skill 中的“运行配置 Skill”说明：

在添加 Skill 弹窗中，来源筛选可以切换到“运行配置skill”。该列表固定展示两个内部配置项，它们只用于创建智能体时配置阶段运行方式，不会出现在 Skill 社区列表中。系统当前在专业模式的代码生成流水线中对这两个配置项做特殊处理。

| 运行配置 Skill | 选中后 | 不选时 |
| --- | --- | --- |
| 跳过该阶段 | 当前阶段不规划 Skill、不读取 Skill，也不生成该阶段代码。运行过程会标记该阶段已跳过，最终生成的完整 pipeline 不应补写该阶段对应代码。 | 当前阶段会按常规流程运行：根据阶段配置、用户需求、数据画像、上游阶段结果、已选 Skill 和知识库等信息继续规划并生成当前阶段代码。 |
| 不使用任何 Skill | 当前阶段不读取任何 Skill，也不做 Skill 检索，直接由大模型基于用户需求、数据画像、上游阶段结果和阶段系统提示词自主生成当前阶段代码。 | 当前阶段会按常规 Skill 流程运行：先在当前阶段候选 Skill 中规划可参考项；在未锁定“只使用已选 Skill”且存在能力缺口时，系统还可以检索公开 Skill 作为补充。 |

注意事项：

- 如果同一阶段同时选择“跳过该阶段”和“不使用任何 Skill”，系统以“跳过该阶段”为准，该阶段会直接跳过。
- 这两个配置项会从普通 Skill 候选中剔除，不会作为普通 Skill 被读取或执行。

### 7.2 编辑智能体

进入方式：打开“我的智能体”，在目标智能体卡片中点击编辑。

编辑页会回填已有配置。修改后可以：

- 保存草稿：保留为未发布或更新草稿。
- 发布：将修改后的配置发布为可使用版本。

注意事项：

- 编辑公开智能体时，请确认变更是否会影响正在使用该智能体的用户。
- 修改阶段提示词、绑定能力或知识库后，建议重新测试一次完整任务。

### 7.3 我的智能体

进入方式：从工作台点击“我的智能体”。

支持功能：

- 查看自己创建的智能体列表。
- 查看统计信息：总数、已发布、草稿、总使用次数。
- 按名称搜索。
- 按状态筛选。
- 按最近创建、收藏最多、浏览最多排序。
- 分页浏览。
- 继续使用、编辑、删除智能体。

常用操作：

- 继续使用：进入该智能体的使用工作台，提交对话或分析任务。
- 编辑：进入创建/编辑页面，修改基础信息、阶段提示词、模型、Skill、Tool 或知识库绑定。
- 删除：弹出确认框后删除智能体。删除后不可恢复，删除前请确认不再需要该智能体。
- 搜索与筛选：如果列表内容较多，可先输入智能体名称关键词，再按发布状态或排序条件缩小范围。

## 8. Skill 管理

Skill 是智能体可调用的业务能力组件，适合封装数据处理、特征工程、模型选择、结果分析等可复用能力。

### 8.1 创建和发布 Skill

进入方式：从工作台点击“创建 Skill”。

需要配置：

- Skill 名称、描述、类别、是否公开、图标。
- Skill 文件上传。
- 入口模块路径和入口函数。
- 输入结构与输出结构。
- Manifest JSON 预览。
- 运行参数，例如超时时间、失败重试次数、是否需要 GPU。

操作步骤：

1. 填写基础信息。
2. 上传 Skill 文件。
3. 配置入口模块路径和入口函数。
4. 配置输入参数结构和输出结果结构。
5. 检查 Manifest JSON 预览。
6. 配置运行参数。
7. 点击“保存草稿”或“发布”。

页面填写建议：

- 名称和描述应写清楚 Skill 能处理什么数据、需要什么输入、会产生什么输出。
- 入口模块路径和入口函数必须与上传文件中的实际代码一致，否则运行时无法调用。
- 输入结构和输出结构会影响智能体后续调用时的参数理解，建议保持字段名称清晰。
- Manifest JSON 预览用于检查当前配置是否符合预期。
- 超时时间、失败重试次数和是否需要 GPU 应按 Skill 的实际运行成本设置。

### 8.2 我的 Skill

进入方式：从工作台点击“我的 Skill”。

支持功能：

- 查看自己创建的 Skill。
- 查看 Skill 统计信息。
- 按名称搜索。
- 按状态筛选。

- 编辑或删除 Skill。

## 9. Tool 管理

Tool 是智能体可调用的工具能力，适合封装明确输入输出的 Python 工具、分析函数或外部能力调用。

### 9.1 创建和发布 Tool

进入方式：从工作台点击“创建 Tool”。

需要配置：

- Tool 名称、描述、图标、类别、是否公开。
- 工具文件上传。
- 入口函数。
- 输入结构与输出结构。
- 运行参数，例如超时时间、失败重试次数、是否需要 GPU。

操作步骤：

1. 填写基础信息。
2. 上传工具文件。
3. 配置入口函数。
4. 配置输入和输出结构。
5. 设置运行参数。
6. 点击“保存草稿”或“发布”。

页面填写建议：

- Tool 名称和描述应说明工具的用途、输入输出和适用场景。
- 上传工具文件后，确认入口函数名称与代码中的函数一致。
- 输入结构要覆盖工具运行所需参数，输出结构要描述工具执行后的结果格式。
- 如果工具运行耗时较长，应适当增加超时时间。
- 如果工具依赖 GPU，请打开需要 GPU 的运行参数。

### 9.2 我的 Tool

进入方式：从工作台点击“我的 Tool”。

支持功能：

- 查看自己创建的 Tool。
- 查看 Tool 统计信息。

可以在只读详情页查看 Tool 信息，并进行收藏或取消收藏。

## 10. 知识库管理

知识库用于为智能体提供可检索的背景资料、业务文档和数据说明。

### 10.1 创建知识库

进入方式：从工作台点击“创建知识库”。

需要配置：

- 知识库名称和描述。
- 系统图标或自定义图标。
- 可见性：私有或公开。
- 启用状态。
- Embedding 提供方、模型和维度。
- Dense 距离度量。
- 是否启用 Sparse 检索。
- 检索策略：稠密检索或混合检索。
- TopK 召回条数。
- 是否启用重排及重排模型。
- 切片策略：段落切片、Token 切片、Markdown 标题切片、固定长度切片。
- Chunk Size、Chunk Overlap、最小切片长度等切片参数。
- dense 和 sparse 预取数量、融合策略、重排候选数量、是否返回 payload、是否改写查询等检索参数。

操作步骤：

1. 填写基础信息。
2. 选择可见性和启用状态。
3. 配置向量化模型和检索策略。
4. 配置切片策略和切片参数。
5. 配置检索参数。
6. 保存知识库配置。

配置填写建议：

- 名称和描述应说明知识库的资料范围，例如设备手册、工艺规范、故障案例或数据字典。
- 私有知识库适合内部资料，公开知识库适合希望被社区用户发现和收藏的资料。
- 如果资料中关键词、术语和短文本匹配很重要，可以开启 Sparse 检索并使用混合检索策略。
- TopK 越大召回内容越多，但也可能引入无关信息；建议从默认值开始调整。
- 切片参数会影响检索粒度。文档段落较长时可以减小 Chunk Size；上下文依赖强时可以适当增加 Chunk Overlap。

### 10.2 我的知识库

进入方式：从工作台点击“我的知识库”。

支持功能：

- 查看自己创建的知识库。
- 查看知识库统计：总数、公开/私有数量、文档总数等。
- 按知识库名称搜索。
- 按公开/私有筛选。
- 按最近创建、文档数量排序。
- 编辑知识库。
- 进入文档管理。
- 删除知识库。

常用操作：

- 编辑：修改知识库基础信息、可见性、启用状态、向量化配置、切片策略和检索策略。
- 文档管理：进入该知识库的文档列表，上传、启用、停用或删除文档。
- 删除：删除知识库前请确认不再需要其中的文档和索引配置。

### 10.3 文档管理

进入方式：在“我的知识库”中找到目标知识库，然后点击“文档管理”。

页面功能：

- 查看知识库概要信息。
- 查看文档统计：文档总数、处理中、处理失败、已启用文档数。
- 上传文档。
- 按文档名搜索。
- 按处理状态筛选：待处理、处理中、已完成、失败。
- 按文件类型筛选。
- 按启用状态筛选。
- 按更新时间、切片数量等排序。
- 查看文档列表和处理阶段状态。
- 启用或停用文档。
- 删除文档。

文档列表字段说明：

| 字段 | 含义 |
| --- | --- |
| 文档信息 | 文档名称、文件类型、文件大小等基础信息。 |
| 总体状态 | 文档当前整体处理状态，例如待处理、处理中、已完成、失败。 |
| 处理阶段状态 | 展示解析、切片、向量化、索引等阶段进度。 |
| 页数/切片数 | 展示文档解析和切片后的规模。 |
| 启用状态 | 控制该文档是否参与知识库检索。停用后文档仍在列表中，但不会用于检索。 |
| 更新时间 | 文档最近处理或配置变更时间。 |

筛选使用建议：

- 想找某个文件时，优先使用文档名搜索。
- 想排查入库问题时，按总体状态筛选“失败”或“处理中”。
- 想控制检索范围时，按启用状态筛选“已启用”或“已停用”。
- 文档较多时，可按更新时间或切片数量排序。

支持上传的常见文件类型：

- `pdf`
- `doc`
- `docx`
- `txt`
- `md`
- `csv`
- `xls`
- `xlsx`
- `json`

### 10.4 上传文档

操作步骤：

1. 在文档管理页点击“上传文档”。
2. 在弹窗中选择一个文件。
3. 确认文件格式和大小满足要求。
4. 点击上传。
5. 上传成功后，文档会进入解析、切片、向量化、索引等处理流程。
6. 处理完成并启用后，文档即可参与知识库检索。

## 14. 常见使用建议

### 14.1 创建智能体前的准备

建议先准备：

- 智能体要解决的业务问题。
- 需要处理的数据类型和样例文件。
- 是否需要知识库支持。
- 是否已有可复用的 Skill 或 Tool。
- 每个阶段需要调用的模型和系统提示词。

### 14.2 知识库使用建议

- 私有资料建议创建私有知识库。
- 对结构复杂的 Markdown 或技术文档，可优先尝试 Markdown 标题切片。
- 表格、代码块较多的文档，建议启用表格单独成块和代码块单独成块。
- 文档上传后需等待处理完成，并确认文档已启用，才会参与检索。

### 14.3 任务运行建议

- 提交需求时尽量说明目标、输入数据、期望输出和评价标准。
- 专业模式下建议上传明确的数据文件，并描述字段含义。
- 任务完成后及时下载输出文件，并为重要会话重命名。

### 14.4 收藏使用建议

- 对常用智能体、Skill、Tool 和知识库进行收藏，便于后续从“我的收藏”快速访问。
- 对不再使用的资源及时取消收藏，保持收藏列表清晰。
