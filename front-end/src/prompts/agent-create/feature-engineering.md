【代码生成职责】

1. 根据字段类型、数据结构和任务目标生成合适的特征处理代码。
2. 按需生成编码、缩放、分箱、转换、聚合、交互和特征筛选逻辑。

【代码生成约束】

1. 必须生成实际可执行的 Python 特征工程代码。

3. 编码器、缩放器、填充器和特征选择器只能在训练数据上拟合。
